# CertChain

Emisión, verificación y revocación de certificados académicos sobre una blockchain simple, en Rust.

Proyecto de Criptografía (TEL252), grupo Spada. En desarrollo: los comandos aún no están implementados.

## Uso

Requiere Rust 1.88 o superior, o Nix (`nix develop`).

```
cargo run -- --help
cargo test
```
